# YOLO Detection Sidecar

A minimal FastAPI server that wraps Ultralytics YOLO11n for object detection.
It runs as a separate process alongside the Next.js dev server.

## Setup (one time)

```bash
# From the project root
cd detector
py -3.13 -m pip install -r requirements.txt
```

Ultralytics will download `yolo11n.pt` (~6 MB) automatically on first startup
and cache it in `~/.config/Ultralytics/` (or `%APPDATA%\Ultralytics\` on Windows).

## Running

Open a second terminal and run:

```bash
cd codejam2026/main-page/detector
py -3.13 -m uvicorn server:app --host 127.0.0.1 --port 8000
```

The server will be available at http://127.0.0.1:8000.

## API

### POST /detect

**Request JSON:**
```json
{ "image": "<base64 string or data-URL>" }
```

**Response JSON:**
```json
{ "labels": ["cup", "bottle", "person"] }
```

### GET /docs

Interactive Swagger UI (auto-generated by FastAPI).

## Environment variables

| Variable | Default | Description |
|---|---|---|
| `YOLO_MODEL` | `yolo11n.pt` | Any Ultralytics model name or local path |

## Notes

- The model is loaded **once at startup**; every request reuses the same instance.
- No GPU required — inference runs on CPU.
- `yolo26n.pt` does not exist in the Ultralytics model zoo. `yolo11n.pt` is the
  current lightest pretrained checkpoint (YOLO11 nano, ~6 MB).
